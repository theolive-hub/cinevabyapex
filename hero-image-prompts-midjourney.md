# Cineva — Hero Image Prompts (Midjourney)

Reworked so every prompt depicts **what the page actually does** — the service, the gear, the work happening — not the headline or slogan. Same template applied to all so the set feels like one shoot.

## The template (applies to all)
`cinematic film still + [THE WORK: concrete service/action on this page] + [setting & practical light] + [composition with negative space] + cinematic, photorealistic, no text + --ar 21:9 --style raw --stylize [150–300]`

**House style baked in:** cinematic film still, shot on Arri Alexa, anamorphic, real working film set, practical LED + tungsten light, atmospheric haze, cyan-and-warm color, photorealistic, no text. Drop `--ar` to `16:9` for a shorter hero crop.

### Tips
- **Consistency:** keep `--style raw` and a similar `--stylize` across all; reuse one `--seed [number]` to push cohesion further.
- **Versioning:** append `--v 7` (or your current default) to lock the model.
- **Faces/hands:** Midjourney can distort them — favor the detail/silhouette backups where people aren't the subject, or plan a retouch pass.
- **Crop:** generate at `21:9`; if a hero needs more height, regenerate at `16:9` rather than cropping.
